# Humanoid Robotics Roadmap

A 30-month structured roadmap to become a robotics engineer, focused on bipedal humanoid robots and sim-to-real transfer.

## 🎯 Goal

Master the full robotics stack — from Linux fundamentals to reinforcement learning for humanoid locomotion — and build a portfolio of real, reproducible projects.

## 🗺️ Roadmap

| Phase | Focus | Timeline |
| :--- | :--- | :--- |
| **Phase 1** | Foundations: Linux, Git, Docker, Python, Math, C++ | Months 1–5 |
| **Phase 2** | Robotics Core: ROS 2, Gazebo, Kinematics, Control, Nav2 | Months 6–13 |
| **Phase 3** | Robotics AI: Computer Vision, Deep Learning, RL, MuJoCo | Months 14–21 |
| **Phase 4** | Specialization: Sim-to-Real, Humanoid Locomotion, Final Project | Months 22–30 |
